# AI tools

> Tools and integrations for working with AI assistants and coding agents.

## Coding agents and token usage

- **[RTK (Rust Token Killer)](https://github.com/rtk-ai/rtk)** — Filter and
  compact command output before a coding agent reads it to reduce input-token
  usage during development.\
  `Windows` `macOS` `Linux` `AI` `CLI`
- **[Caveman](https://github.com/JuliusBrussee/caveman)** — Reduce an AI coding
  agent's prose output with a compact communication skill and proxy while
  preserving code, commands, and exact error messages.\
  `AI` `Coding agents` `Token usage`

## MCP integrations

- **[Zammad MCP](https://github.com/basher83/Zammad-MCP)** — Connect AI
  assistants to Zammad to search and manage support tickets, users,
  organizations, and attachments through MCP.\
  `AI` `MCP` `Zammad` `Help desk`
