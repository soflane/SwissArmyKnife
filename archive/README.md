# Archive

> Historical entries that are no longer recommended or actively maintained.

Archived entries remain here to explain previous choices and point readers to
safer or better-maintained replacements.

## Windows cleanup tools

- **[CCleaner](https://www.ccleaner.com/ccleaner/download)** — Previously
  listed as a cleanup utility; removed from the recommended catalog because of
  advertising and bundled-software concerns. Use
  [Bulk Crap Uninstaller](../tools/README.md#application-management) for
  uninstall cleanup or BleachBit for temporary-file cleanup.  
  `Windows` `Archived`

## Android applications

- **[YouTube Vanced](https://github.com/YTVanced)** — The original project is
  no longer maintained. The link is retained for historical context, not as an
  installation recommendation.  
  `Android` `Archived`

## Unavailable services and publishers

- **Deseat.me** — Previously helped discover and clean up accounts associated
  with an inbox. The service has remained unavailable and is no longer linked
  from the active catalog.  
  `Web` `Privacy` `Archived`
- **KC Softwares** — The publisher ended operations in 2023 and its official
  website and downloads are unavailable. Its directory entry and
  IDPhotoStudio recommendation were removed from the active catalog.  
  `Windows` `Publisher` `Archived`

## Older Windows utilities

- **WindowGrid** — Its original website is unavailable. Use the window-layout
  features in
  [Microsoft PowerToys](../tools/README.md#customization-tools) instead.\
  `Windows` `Productivity` `Archived`
- **Airytec Switch Off** — The last published version predates current Windows
  releases and current compatibility is unclear. Use Windows Task Scheduler or
  another maintained automation tool for scheduled power actions.  
  `Windows` `Automation` `Archived`
