# Web tools and resources

> Browser-based utilities, technical references, and service status pages for
> quick tasks that do not require a local installation.

## Web server tools

- **[Cipherlist.eu](https://cipherlist.eu/)** — Generate current SSL/TLS cipher
  recommendations for common web servers.  
  `Web` `TLS` `Server configuration`
- **[EcoIndex](https://www.ecoindex.fr/)** — Estimate the environmental impact
  of a web page and identify possible improvements.  
  `Web` `Audit` `Sustainability`
- **[NGINXConfig](https://www.digitalocean.com/community/tools/nginx)** — Generate
  an Nginx configuration interactively for common deployment patterns.  
  `Web` `Nginx` `Configuration`
- **[Minixed](https://github.com/lorenzos/Minixed)** — Serve a compact,
  browsable PHP directory index when a full file manager is unnecessary.  
  `Web server` `PHP` `Open source`

## Development and design

- **[Huemint](https://huemint.com/)** — Generate color palettes for interfaces,
  illustrations, and brand systems.  
  `Web` `Design` `Colors`
- **[IT-Tools](https://it-tools.tech/)** — Use a large collection of converters,
  encoders, formatters, generators, and network helpers in one interface.  
  `Web` `Development` `Open source`
- **[Composerize](https://www.composerize.com/)** — Convert a `docker run`
  command into a Docker Compose service definition.  
  `Web` `Docker` `Development`
- **[diagrams.net](https://app.diagrams.net/)** — Create flowcharts, network
  diagrams, and other technical visuals in a browser.  
  `Web` `Diagrams`

## Mail diagnostics

- **[Unspam Email](https://unspam.email/)** — Send a test message and inspect
  domain authentication, reputation, and message-content findings.  
  `Web` `Email` `Diagnostics`
- **[Mail-Tester](https://www.mail-tester.com/)** — Score a test email for spam,
  authentication, and deliverability problems.  
  `Web` `Email` `Diagnostics`

## Image tools

- **[BRIA Background Removal](https://huggingface.co/spaces/briaai/BRIA-RMBG-1.4)** —
  Remove an image background through a hosted model demonstration.  
  `Web` `Images` `AI`
- **[QuickPic](https://quickpic.t3.gg/)** — Convert SVG files, square images,
  and round corners with small browser-based tools.  
  `Web` `Images`
- **[MockUPhone](https://mockuphone.com/)** — Place app screenshots inside
  mobile-device mockups for presentations and app-store visuals.
  `Web` `Images` `Mobile design`
