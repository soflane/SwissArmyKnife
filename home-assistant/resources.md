# Home Assistant resources

> Official references and community projects worth keeping close at hand.

## Official and community references

- **[Home Assistant documentation](https://www.home-assistant.io/docs/)** — Find
  current installation, configuration, automation, dashboard, and integration
  guidance.  
  `Official` `Documentation`
- **[Home Assistant Community](https://community.home-assistant.io/)** — Search
  troubleshooting discussions, blueprints, configuration examples, and project
  announcements.  
  `Community` `Support`
- **[HACS documentation](https://hacs.xyz/docs/use/)** — Install and manage
  community integrations and frontend resources.  
  `HACS` `Documentation`
- **[Awesome Home Assistant](https://github.com/frenck/awesome-home-assistant)** —
  Browse a curated collection of integrations, add-ons, dashboards, and related
  projects.  
  `Directory` `Community`
- **[Blueprint Exchange](https://community.home-assistant.io/c/blueprints-exchange/53)** —
  Find reusable automation blueprints shared by the community.  
  `Automation` `Blueprints`
