# Self-hosted projects

> Services and infrastructure tools that can run on hardware you control.

## Applications

- **[Stirling PDF](https://www.stirlingpdf.com/)** — Merge, split, OCR,
  compress, convert, sign, and edit PDF files in a locally hosted web
  application.  
  `Self-hosted` `Docker` `PDF` `Open source`
- **[Wolweb](https://github.com/unikiteam/wolweb)** — Send Wake-on-LAN packets
  through a small web interface that can run in a container.  
  `Self-hosted` `Docker` `Wake-on-LAN`

## Infrastructure

- **[Proxmox VE Helper-Scripts](https://community-scripts.github.io/ProxmoxVE/)** —
  Deploy and maintain common services on Proxmox VE with community-maintained
  scripts.  
  `Proxmox` `Automation`
