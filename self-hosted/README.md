# Self-hosted projects

> Services and infrastructure tools that can run on hardware you control.

## Applications

- **[Stirling PDF](https://www.stirlingpdf.com/)** — Merge, split, OCR,
  compress, convert, sign, and edit PDF files in a locally hosted web
  application.  
  `Self-hosted` `Docker` `PDF` `Open source`
- **[Wolweb](https://github.com/unikiteam/wolweb)** — Send Wake-on-LAN packets
  through a small web interface that can run in a container.  
  `Self-hosted` `Docker` `Wake-on-LAN`
- **[ConvertX](https://github.com/C4illin/ConvertX)** — Convert batches of
  documents, images, audio, video, and other files through a locally hosted
  web interface.\
  `Self-hosted` `Docker` `File conversion`

## Device and print management

- **[Bambuddy](https://bambuddy.cool/)** — Monitor Bambu Lab printers, archive
  print files, queue jobs, and track materials and print costs on your own
  network.\
  `Self-hosted` `3D printing` `Bambu Lab`
- **[NetLock RMM](https://github.com/0x101-Cyber-Security/NetLock-RMM)** —
  Monitor and manage endpoints remotely from a self-hosted administration
  console for IT teams and managed service providers.\
  `Self-hosted` `Remote administration` `Monitoring` `Open core`

## Maps and public data

- **[God's Eye View](https://github.com/bilawalsidhu/gods-eye-view)** — Explore
  aircraft, ships, satellites, and other public data on a locally hosted 3D
  globe, with optional AI voice control.\
  `Windows` `macOS` `Linux` `Self-hosted` `Maps` `Public data`

## Infrastructure

- **[Error Pages](https://github.com/tarampampam/error-pages)** — Serve themed
  HTTP error pages behind Traefik, Nginx, or other reverse proxies with a small
  HTTP server or Docker container.\
  `Self-hosted` `Docker` `HTTP` `Reverse proxy`
- **[Proxmox VE Helper-Scripts](https://community-scripts.github.io/ProxmoxVE/)** —
  Deploy and maintain common services on Proxmox VE with community-maintained
  scripts.  
  `Proxmox` `Automation`
